# ISO Documentation Pack (Index)

## 1. Purpose
This documentation pack provides project-level documentation for the ERA Website system consisting of:
- A backend API service (`era_website_backend`) implemented in Ruby on Rails.
- A frontend web application (`era-web-gateway-main`) implemented with Vite + React + TypeScript.

It is structured to support:
- ISO 9001 (Quality Management System) project documentation
- ISO/IEC 27001 (Information Security Management System) system documentation
- ISO/IEC 12207 / ISO/IEC 15288 (Software/System life cycle processes)
- ISO/IEC 25010 (Software product quality model) quality evidence

## 3. Scope
These documents cover:
- Source code repositories and build outputs
- Runtime environments (development, staging, production)
- Operational and security controls for the system

Out of scope unless explicitly added:
- Organization-wide policies not specific to this system
- Third-party platforms outside the control boundary
